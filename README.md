# Basic Packet Sniffer + ARP Spoofing Detector

## Project Overview
This project is a simple network security monitoring tool developed using Python and Scapy. It captures live network packets, analyzes ARP traffic, monitors IP-MAC address mappings, and detects possible ARP spoofing activities.

## Features
- Live packet sniffing
- ARP packet monitoring
- IP and MAC address detection
- Basic ARP spoofing detection
- Security logging with timestamps
- Network activity monitoring

## Technologies Used
- Python
- Scapy
- Networking Fundamentals
- ARP Protocol Analysis

## Ethical Note
This project was developed and tested in a safe local environment for educational and ethical learning purposes only.
